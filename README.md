# 🐍 Snake Game

A classic Snake Game built using **HTML, CSS, and JavaScript**. Control the snake, eat the food, grow longer, and try to achieve the highest score without hitting the walls or yourself.

## 🎮 Features

- Simple and interactive user interface
- Smooth snake movement
- Score tracking
- Food generation at random positions
- Game-over detection
- Keyboard controls
- Responsive design

## 🛠️ Technologies Used

- **HTML5** – Game structure
- **CSS3** – Styling and layout
- **JavaScript** – Game logic and controls

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/satyamvishwa2006-coder/Snake-game.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start playing!

## 🕹️ Controls

- ⬆️ **Arrow Up** – Move Up
- ⬇️ **Arrow Down** – Move Down
- ⬅️ **Arrow Left** – Move Left
- ➡️ **Arrow Right** – Move Right
